# Faculdade

Este repositório reúne projetos e atividades desenvolvidas durante a formação acadêmica, com foco em HTML, CSS, JavaScript e projetos web responsivos.

## Objetivo

Organizar e versionar os exercícios, projetos e estudos realizados ao longo da faculdade, servindo como portfólio e espaço de aprendizado prático.

## Estrutura do repositório

```text
Faculdade/
├── projeto01/
├── projeto02/
├── projeto03/
├── ...
├── README.md
└── assets/
```

## Tecnologias principais

- HTML5
- CSS3
- JavaScript
- Frameworks front-end (como Materialize)
- Git e GitHub

## Projetos incluídos

- Landing pages
- Interfaces responsivas
- Exercícios de front-end
- Estruturas básicas de HTML/CSS/JS

## Como visualizar os projetos

1. Clone o repositório:

```bash
git clone https://github.com/Kayosena01/Faculdade.git
```

2. Acesse a pasta do projeto desejado.
3. Abra o arquivo `index.html` em um navegador ou utilize um servidor local como Live Server no VS Code.

## Como contribuir

1. Faça um fork do projeto.
2. Crie uma branch para sua alteração.
3. Faça o commit das mudanças.
4. Abra um pull request.
