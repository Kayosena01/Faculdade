# Projeto 02 - Landing Page com Materialize

Este projeto é uma landing page responsiva desenvolvida com HTML, CSS e o framework Materialize CSS.

## Objetivo

O objetivo principal desta página é demonstrar a construção de uma interface moderna, com navegação, seção hero, cards de recursos e área de contato, mantendo um layout limpo e responsivo.

## Tecnologias utilizadas

- HTML5
- CSS3
- Materialize CSS
- JavaScript
- jQuery

## Estrutura do projeto

```text
projeto02/
├── index.html
├── css/
│   ├── estilos.css
│   └── materialize.min.css
├── js/
│   ├── configuracoes.js
│   └── materialize.min.js
└── README.md
```

## Funcionalidades

- Navbar responsiva
- Menu mobile com sidenav
- Layout em estilo landing page
- Seção de apresentação com CTA
- Cards de recursos
- Área de destaque e contato
- Visual adaptável para desktop e mobile

## Como visualizar localmente

1. Abra a pasta do projeto no Visual Studio Code.
2. Instale a extensão Live Server.
3. Clique com o botão direito em `index.html`.
4. Selecione a opção `Open with Live Server`.

## Como publicar no GitHub Pages

1. Acesse o repositório no GitHub.
2. Vá em `Settings` → `Pages`.
3. Em `Source`, escolha `Deploy from a branch`.
4. Selecione a branch `main` e a pasta `/root`.
5. Salve as configurações.

Depois disso, a página ficará disponível em uma URL semelhante a:

```text
https://seu-usuario.github.io/SeuRepositorio/projeto02/
```

## Personalização

Você pode alterar facilmente os textos, cores e elementos visuais editando o arquivo `index.html` e o CSS em `css/estilos.css`.

## Observação

Este projeto foi criado como exemplo de uma landing page moderna e pode ser usado como base para páginas de apresentação, portfólios, startups ou sites institucionais.
